概要

個別 feature の細かい履歴ではなく、今の runtime-dev に実際に見えている追加点をまとめています。

Battle / Team

選出、Team Viewer、All Ability、BGM、aftercare、item restore を統合。

Pokemon / Shop

Pokemon Vendor、sealed recruit、held item token、State Editor、進化停止。

Challenge

Champions run session の開始、checkpoint、retire、lose、clear restore。

Summary UX

Unified Move Relearner、Tera badge、ability slot 表示切替を Summary に集約。

Field / Map

Field Kit、no encounter flag、Map Asset Relinker、Fly icon style support。

Tooling

partygen、scout pool generator、learnset generator、Tauri GUI release workflow。
